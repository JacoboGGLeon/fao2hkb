# FAO2HKB  
**FAOSTAT Bulk Downloads → Hierarchical Knowledge Base (HKB) Generator**

FAO2HKB is a reproducible pipeline that transforms FAOSTAT domain tables into a
**Hierarchical Knowledge Base (HKB)** with 3 structured levels:

| Level | File | Description |
|-------|------|--------------|
| **L3** | DOMAIN.jsonl  | Domain table (GT + QI) |
| **L2** | SERIES.jsonl  | Unique time-series keys (Area, Item, Element, Unit) |
| **L1** | RECORDS.jsonl | Time-series data records (Year–Value) |

It is currently focused on the FAOSTAT tables:
- **GT — Emissions Totals**
- **QI — Production Indices**

These two domains together form the data product:
**FAOSTAT HKB GT+QI @ 2025**

---

## 🚀 Installation

### From source (recommended for development)
```bash
git clone https://github.com/JacoboGGLeon/fao2hkb.git
cd fao2hkb
pip install -e .
````

### With embeddings support (optional)

```bash
pip install -e ".[embeddings]"
```

---

## ⚙️ Quick Start

```bash
python -m fao2hkb run --config examples/config.example.basic.yaml
```

To enable embeddings (L2/L3 vector fields):

```bash
python -m fao2hkb run --config examples/config.example.embeddings.yaml
```

This produces:

```
runs/
└─ FAO2HKB_YYYYMMDD_HHMMSS/
   ├─ artifacts/data/
   │   ├─ DOMAIN.jsonl
   │   ├─ SERIES.jsonl
   │   └─ RECORDS.jsonl
   ├─ config.resolved.yaml
   └─ manifest.json
```

## 📁 Examples

### 1) Basic configuration

`examples/config.example.basic.yaml`

```yaml
run:
  output_root: "./runs"
  seed: 42

sources:
  - table: 1
    url: https://bulks-faostat.fao.org/production/Emissions_Totals_E_All_Data_(Normalized).zip
  - table: 2
    url: https://bulks-faostat.fao.org/production/Production_Indices_E_All_Data_(Normalized).zip

embeddings:
  enabled: false
```

### 2) With embeddings

`examples/config.example.embeddings.yaml`

```yaml
embeddings:
  enabled: true
  model_name: "Qwen/Qwen3-Embedding-0.6B"
  device: "auto"
  batch_size: 64
  l2_normalize: true
```

## 🧱 HKB Schema (Summary)

```
L3: {
  "Domain": "...",
  "Sub_domain": "...",
  "Domain_table": "GT or QI"
}

L2: {
  "series_key": "...",
  "Area": "...", "Item": "...", "Element": "...", "Unit": "...",
  "description": "text",
  "embedding": [vector if any]
}

L1: [
  {"Year": 1961, "Value": ...},
  {"Year": 1962, "Value": ...},
  ...
]
```

## 🔁 Reproducibility

* `manifest.json` → counts, sizes, SHA-256 hashes
* `config.resolved.yaml` → exact configuration used
* deterministic seeds for predictable runs

Re-run any published dataset with:

```bash
fao2hkb run --config config.resolved.yaml
```
